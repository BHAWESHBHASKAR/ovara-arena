How it works

An unmodified coding agent works real tasks in a sandbox. It never touches the network, the shell or a real key directly. OVARA does, on its behalf, and writes down every decision.

01

A real coding agent

OpenCode and a Nemotron 3 Super agent run unmodified inside an OVARA sandbox, with a repo, a shell and a task queue.

02

OVARA sits on the wire

Every command, HTTP request, model call and git push goes through OVARA, which allows, holds or blocks it against policy.

03

Holds wait for you

Pushes, deploys and unknown destinations pause in the Approvals inbox until a human approves or denies them.

04

Every decision is a receipt

Each outcome is signed and hash-chained to the one before it, so anyone can verify nothing was edited or dropped.

Models
